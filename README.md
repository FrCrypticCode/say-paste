/// Say & Paste

Say & Paste is a lightweight Windows utility designed to provide quick access to frequently used URLs.
The application allows users to associate a URL with a custom keyword, making it easy to retrieve and instantly copy the corresponding link to the Windows clipboard whenever needed.

/// Features
- Associate a URL with a custom keyword
- Search for a URL using its keyword
- Automatically copy the retrieved URL to the Windows clipboard
- Simple and responsive native Windows interface
- Local data management

/// Technical Details
- Developed in Rust
- Built directly on the Win32 API
- No external dependencies
- Lightweight executable with near-instant startup
- Windows-only application
